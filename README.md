这是一个持续更新的影视文化词典，用于整理女性视角、人物关系、情感叙事和亲密场景中常见的表达方式。

## 核心词条

### 女性凝视

不是简单地把观看对象从女性换成男性，而是关注女性角色是否拥有欲望、选择和表达感受的主体性。

### 情绪安全感

人物在关系中能够表达拒绝、犹豫和需求，并得到另一方的尊重。

### 双向欲望

亲密关系并非由一方推动，而是通过双方的行为、语言和情绪共同建立。

### 叙事主动权

角色是否能够决定关系如何开始、推进和结束，而不是单纯被剧情安排。

### 氛围叙事

通过光线、声音、距离、服装和空间营造情绪，而不是只依赖直接的身体展示。

### 关系张力

人物之间因为身份、过去、距离或未表达的感情而产生的持续吸引力。

## 可使用的分析维度

分析一部作品时，可以观察：

1. 女性角色是否拥有明确动机
2. 亲密关系是否建立在双向表达之上
3. 镜头是否尊重角色的主体性
4. 情感发展是否具有合理铺垫
5. 人物边界是否得到尊重
6. 场景是否服务于人物关系
